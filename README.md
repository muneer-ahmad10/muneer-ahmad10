## 🏗️ Under the hood

<details>
<summary><b>📚 How my RAG chatbot works</b> (click to expand)</summary>

```mermaid
flowchart LR
    A[PDF upload] --> B[Text extraction]
    B --> C[500-char chunks]
    C --> D[Sentence-Transformer embeddings]
    D --> E[(FAISS index)]
    Q[User question] --> F[Query embedding]
    F --> E
    E --> G[Top-k chunks]
    G --> H[FLAN-T5]
    Q --> H
    H --> I[Grounded answer]
```

</details>

<details>
<summary><b>🧠 How my Mini GPT is built</b> (click to expand)</summary>

```mermaid
flowchart TB
    T[Token + positional embeddings] --> B1
    subgraph B1[Transformer block × N]
        direction TB
        L1[LayerNorm] --> A[Causal multi-head self-attention] --> R1[+ residual]
        R1 --> L2[LayerNorm] --> F[Feed-forward] --> R2[+ residual]
    end
    B1 --> LN[Final LayerNorm] --> O[Linear → next-token logits]
```

</details>
